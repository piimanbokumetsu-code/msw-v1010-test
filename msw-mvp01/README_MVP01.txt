# MSW患者管理 Ver.1.0.21-MVP01（検証候補）

**実在患者の情報はまだ入力しないでください。テスト用の架空患者で確認する独立版です。**

目的：OCRを完成させる前に、Ver.1.0.20の患者管理機能を基に「今日の業務」を優先して使えるようにする。

### 追加した機能
- 患者の「退院支援」タブでタスクを追加するとき、任意の対応期限と「優先対応」を指定可能。
- 下部「今日・要対応」で期限切れ・今日・今後・期限なしを分けて表示。期限なしタスクも残す。
- 従来のタスクは期限なしとして安全に表示（データ形は後方互換）。
- 既存Ver1.0.20と異なる暗号化IndexedDB保存先 `mswdb_mvp01_isolated` を使用。GitHub Pagesではパスが違っても同一originなので、意図的に分離。
- OCRの新機能、台帳へのOCR自動反映は含めない。患者情報の新規登録／手動退院などの既存v1.0.20の機能は残しているため、架空データのみで確認。

### テスト方法
1. `piimanbokumetsu-code/msw-v1010-test`の新しいフォルダ`msw-mvp01-test/`に、ZIP展開内容のファイルだけを置く（まだアップロードしていない）。
2. iPad mini Safariで専用URLを開き、新しいテスト暗証を設定する。既存のVer.1.0.20からデータは自動移行されない。
3. 架空患者を1名登録→退院支援タブで「今日の期限」「期限なし」「期限切れ」を作り、画面下「今日・要対応」で分類表示を確認する。
4. 設定で暗号化バックアップを書き出し、保存ファイルを確認。別途復元試験は必須。
5. 実在患者データ投入や現場運用の開始は、院内の個人情報保護・端末管理の承認と、復元試験およびiPad mini実機検証の後。
