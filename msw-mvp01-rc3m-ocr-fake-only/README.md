# MSW MVP01 日誌OCR統合テスト（架空データ限定）
更新日：2026-10-22

## 構成
- テスト用配置先: `msw-mvp01-rc3m-ocr-fake-only/`
- 本体: `index.html`（RC3Mの架空患者専用プレビューから派生、保存DBは `mswdb_mvp01_rc3m_ocr_faketest_20261022` に分離）
- OCR統合: `ocr-integration.js`（写真最大4枚、逐次読み取り、原本照合、手入力欄への転記、端末内メモリでのみ保持）
- OCR実行部品と合成書式位置検出: `../ocr-auto-stage22/ocr/`, `../ocr-auto-stage22/layout.js`, `../ocr-auto-stage22/sample/` の同一サイト上のファイルを使用
- 閲覧URL想定: https://piimanbokumetsu-code.github.io/msw-v1010-test/msw-mvp01-rc3m-ocr-fake-only/

## 実装した機能
- iPad mini画角に合わせて撮影画像の幅・高さを制限し、入力欄が横にはみ出ないUI
- OCR結果を写真と同時表示し、日付・入院氏名・退院氏名・人数を人が照合するUI
- 同一サイトのTesseract.js 5.1.1/WASM/日本語辞書を利用
- 既知の合成日誌書式では日付と入退院の氏名欄を認識
- 未知の書式では自動配置はせず、全文OCRに切り替える
- 確認済みの氏名は、明示操作時だけ新規患者の手入力欄へ転記（登録ボタンは別途必要）
- 写真の一時Object URL、OCR Canvas、OCRワーカーは適時解放。写真はDB・サーバー・GitHubへアップロードしない
- アプリロック・画面を離れた時に未登録写真を破棄

## 検証したこと
- `node --check`：本体インラインスクリプトと統合JSの構文合格
- ブラウザ（OCR出力を模擬したヘッドレステスト）：写真追加 → OCRボタン → 日付/氏名反映 → 照合チェック未完了の確定禁止 → 手入力欄へ転記 → 自動登録無し（PASS）
