# 分割バックアップ 独立検証（2026-10-29）
現行本番のバックアップ上限120MiB超で作成不能となった問題に対し、患者写真を削除せず、安全な分割書き出しと整合性チェックの試作。
**本番アプリとは独立・本番の患者情報を選択禁止**。ランダム風の架空暗号文でのみ試験。生成時の各ファイルは40KiB以下の検証用。マニフェスト記載の SHA-256 で欠落・改変・重複を検出し、復元前検証では一切IndexedDBを書き換えない。
ユーザーのiPad miniでの実機起動、全パート検査、故意の欠落の検出、既存120MiB+データの処理は未試験。本番組込前に **暗号化状態のまま分割書き出し、データ復元をトランザクション安全に行う機能、低メモリ試験** が必要。本番/mainは未変更。

## iPad miniファイル選択 修正 2026-10-30
- iPad mini Safariでマニフェストだけ選択可能、.mswpartが選択不能（OSの独自拡張子フィルタ問題と推定）。
- ファイル入力からacceptフィルタを除去。代わりにJSで架空ファイル名（fake-backup-manifest.json, fake-backup-part-001〜005.mswpart）とサイズを厳密に許可。実患者バックアップは拒否し、内容を読まない。
- iPad Filesの複数選択が困難でも、ファイル選択を繰り返し、各セッションで1ファイルずつ選択済みへ追加できるように変更。6個揃えば整合性検査可能。「選択をやり直す」も追加。
- 検証ページ版 v=02。実機での修正版動作確認は未実施。GitHubコードの構文確認は合格。
