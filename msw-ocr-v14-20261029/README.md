# MSW日誌OCR v14（2026-10-29） — 架空日誌の自動拡大照合

## 開発背景
iPad mini Safariでのv13検証：2枚目「虹→町」「葵→装」、3枚目「葵→装」が残存。複数の画像前処理や1文字PSM10でも判別できない例がある。OCR誤認識が解消したとは決して扱わない。

## v14の改善（画像認識エンジンはv13と同じ）
- 入退院氏名を自動で切り出した原本拡大プレビューを「氏名候補を行ごとに修正」に並べて表示。ユーザーの手動青枠囲み不要。
- 各行の「手入力」ボタンで該当1名を直接修正できる。氏名の変更では確認済み・3チェックを解除し、再照合を促す。
- プレビュー画像は端末RAM上の一時的な data URL。バックアップや患者登録に保存せず、写真を消去すると破棄。
- 候補が見つからなかった旨の表示、Tesseract v13の複数方式試行、原本照合必須、架空データ制限はそのまま継承。
- 印字日付・人数と氏名は原本照合してから完了扱いとする。

## 検証
- v14 JS構文テスト合格、拡大プレビュー生成とCanvas解放のモックテスト合格。
- コードで、手入力が指定氏名1行のみを変更し、確認状態を無効化することを確認。
- **未確認：iPad mini Safari実機での拡大表示・手入力の操作性、氏名自動OCRの精度向上はない。**
- 既存の独立v13と本番JP01は一切変更しない。
